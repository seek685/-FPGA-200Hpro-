Memory interface reminder:
  The optimized core fetches instructions by combinational ROM read.
  Adding a registered ROM output changes the CPU interface timing.
  Data RAM requires a clocked one-cycle read; byte writes can be inferred by
  individual mem[word_index][7:0], [15:8], [23:16], [31:24] assignments.
  Do not reset every RAM word, as that defeats FPGA RAM inference.
